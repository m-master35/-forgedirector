# ForgeDirector — 5-Minute Integration Kit

ForgeDirector is a post-generation QA gate for AI-generated short-form video.

Use it after your video generator:

```text
GENERATE → UPLOAD → ANALYZE → ACCEPT / REVISE / REGENERATE
```

Live API:
https://rapidapi.com/mmaster35/api/forgedirector-video-creative-intelligence

## What you get back

`POST /v1/analyze` returns structured JSON designed for automation, including:

- `analysis.qualityGate` — accept / revise / regenerate decision
- creative `scores`
- explicit production-rule `compliance`
- first-three-second `hook` analysis
- timestamped `timeline` diagnostics
- `cta` assessment
- ranked fixes
- regeneration-ready prompts

Use the quality gate as the machine-readable production decision, then use the diagnostics and regeneration prompts when the result needs revision.

## Step 1 — Create an upload ticket

Call:

```http
POST /v1/uploads
Content-Type: application/json
```

Body:

```json
{
  "contentType": "video/mp4",
  "sizeBytes": 2848208
}
```

Important:

- `sizeBytes` must be the exact byte size of the file.
- Preserve the returned upload Content-Type and Content-Length requirements.
- The response returns an `assetId` and a short-lived signed PUT URL.

## Step 2 — Upload the video

HTTP PUT the unmodified MP4 bytes to the returned signed URL.

Conceptually:

```bash
curl -X PUT "<SIGNED_UPLOAD_URL>" \
  -H "Content-Type: video/mp4" \
  -H "Content-Length: 2848208" \
  --data-binary "@clip.mp4"
```

A successful upload returns HTTP 200.

Do not send the upload through RapidAPI; the signed URL points directly to the private upload destination.

## Step 3 — Analyze the uploaded video

Call:

```http
POST /v1/analyze
Content-Type: application/json
```

Example:

```json
{
  "assetId": "YOUR_ASSET_ID",
  "platform": "TikTok",
  "objective": "conversion",
  "audience": "Young professionals",
  "durationSeconds": 30,
  "context": "Premium productivity app. Keep recommendations credible and direct.",
  "requirements": {
    "mustShow": ["Brand logo", "App interface"],
    "mustNotShow": ["Competitor logos"],
    "mustIncludeText": ["Start free"],
    "continuityRules": ["Use the same lead character throughout"],
    "ctaRequired": true
  }
}
```

Optional:

- supply `transcript` when exact spoken-word analysis matters.

## Step 4 — Branch on the quality gate

Pseudocode:

```js
const result = await analyzeVideo(assetId);

switch (result.analysis.qualityGate.decision) {
  case "accept":
    ship(result);
    break;

  case "revise":
    queueEdits(result.analysis);
    break;

  case "regenerate":
    regenerate(result.analysis);
    break;

  default:
    sendForReview(result);
}
```

Treat the returned schema as the source of truth for the exact decision field/value names in your client.

## RapidAPI authentication

Subscribe to ForgeDirector in RapidAPI and use the authentication headers generated by RapidAPI's code snippet for your account.

Typical RapidAPI calls include:

```http
X-RapidAPI-Key: <YOUR_KEY>
X-RapidAPI-Host: <HOST_SHOWN_BY_RAPIDAPI>
```

Copy these values from the RapidAPI consumer console rather than hard-coding values copied from another account.

## Optional planning workflow

ForgeDirector can also create and revise video-production manifests before generation.

`POST /v1/plan` example:

```json
{
  "brief": "Create a premium 30-second vertical ad for a productivity app aimed at young professionals. Keep the language credible and direct.",
  "constraints": {
    "platform": "TikTok",
    "aspectRatio": "9:16",
    "durationSeconds": 30
  }
}
```

A successful planning response includes `meta.qualityGate.passed == true`.

Additional endpoints:

- `POST /v1/revise`
- `POST /v1/qa`
- `GET /health`

## Integration pattern

For an AI-video SaaS or agent:

```text
1. Generate video
2. Request ForgeDirector upload ticket
3. PUT generated video
4. Analyze
5. Read quality gate
6. Accept, revise, or regenerate
7. Repeat only when necessary
```

This keeps ForgeDirector model-agnostic: the video may come from any generation engine as long as it fits the supported short-form upload limits.

## Current production limits

- maximum video size: 30 MiB
- maximum video duration: 120 seconds
- intended for short-form video QA

## What ForgeDirector is not

ForgeDirector scores are creative-quality heuristics, not guarantees or predictions of views, retention, sales, ROAS, or virality.

For exact speech verification, provide a transcript.
